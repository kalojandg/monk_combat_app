# Настройка на Google Cloud Text-to-Speech

Това ръководство те превежда от нула до работещ глас за бутона „🔊 Произнеси".
Гласът на Пийс е мъж, монк, юан-ти — фиксиран, без настройки в апката.

Ключът вече е попълнен в `modules/tts.js` (в `TTS_CONFIG.apiKey`). Ако апката
мълчи или искаш да смениш проекта/гласа, мини по стъпките отдолу.

> ⚠ Навсякъде по-долу `API_KEY` е плейсхолдър. Истинският ключ стои само в
> `modules/tts.js` — не го копирай в този документ, в issue-та или в скрийншоти.

---

## 1. Създаване на API ключ

1. Отвори [Google Cloud Console](https://console.cloud.google.com/).
2. Създай нов проект (горе вляво → *New Project*) или избери съществуващ.
3. *APIs & Services* → *Library* → потърси **Cloud Text-to-Speech API** → **Enable**.
4. *APIs & Services* → *Credentials* → **Create credentials** → **API key**.
5. Копирай генерирания ключ.

> 💳 **Билинг:** Google изисква закачен billing account, за да разреши API-то
> ИЗОБЩО. Това е условие за включване, а не разход — при това ползване оставаш в
> безплатния слой (виж т. 4). Без закачен билинг Enable ще откаже.

---

## 2. Ограничаване на ключа (задължително — ключът се комитва)

Ключът е в публичното репо, затова го заключваме така, че изтекъл да е почти
безполезен. В *Credentials* → клик върху ключа:

1. **Application restrictions** → **HTTP referrers (web sites)** → добави:
   - домейна на GitHub Pages, напр. `https://<user>.github.io/*`
   - `http://localhost:45278/*` — за локална работа (`npm run serve`)

   > ⚠ Ако `http://localhost:45278/*` липсва, локалното пускане получава **403**
   > и апката мълчи на компа (пада към вградения глас).

2. **API restrictions** → **Restrict key** → избери само
   **Cloud Text-to-Speech API**.
3. **Save**.

---

## 3. Избраният глас

- Български: **`bg-BG-Chirp3-HD-Sadaltager`** (MALE)
- Английски: **`en-US-Chirp3-HD-Sadaltager`** (MALE) — за `tasha-jokes.json`

Избрани от потребителя след прослушване. Български има 31 гласа, от които 16
мъжки. Смяна на гласа = едно поле в `TTS_CONFIG.voices` в `modules/tts.js`.

**Пълен списък с гласове:**

```bash
curl -H "Referer: http://localhost:45278/" \
  "https://texttospeech.googleapis.com/v1/voices?languageCode=bg-BG&key=API_KEY"
```

> ⚠ Хедърът `Referer` е задължителен — ключът е ограничен по HTTP referrer и без
> него връща 403. Смени `bg-BG` с `en-US` за английските гласове.

**Прослушване през браузър (без ключ):** Google Cloud Console → *Speech* →
*Text-to-Speech* → *Synthesise*.

### 3б. Ограничения на Chirp3-HD гласовете (проверени срещу живото API)

Документирани тук, за да не се въвеждат наново:

- `audioConfig.pitch` → **400** `This voice does not support pitch parameters at
  this time.` Дълбочината идва от самия глас, не от параметър. **Не добавяй pitch.**
- `input.prompt` (стилови инструкции с думи) → **400** `Prompt is only supported
  for Gemini TTS.` Това е друг бекенд — не се ползва тук.
- `audioConfig.speakingRate` (0.25..4.0) — **работи**.
- `input.ssml` с `<break>` и `<prosody rate>` — **работи** (носи подигравателния
  тайминг).
- `audioEncoding: 'MP3'` — **работи**, отговорът е готов за `<audio>`.

## 4. Цена

Безплатният слой (към момента на писане, сверявай на
[страницата с цените](https://cloud.google.com/text-to-speech/pricing)):

| Тип глас            | Безплатно на месец   |
|---------------------|----------------------|
| Standard            | 4 000 000 знака      |
| Neural2 / WaveNet   | 1 000 000 знака      |
| Studio              | 100 000 знака        |

Целият корпус реплики е ~72 700 знака — дори всичките 1157 реплики са ~7% от една
месечна квота. Практически неизчерпаем при това ползване.

- **Твърд стоп:** сложи *quota limit* на самото API (*APIs & Services* → *Quotas*).
  Budget alert само известява — НЕ спира заявки.
- Тарифите се менят — сверявай ги на страницата с цените.

## 5. Настройки в `TTS_CONFIG` (`modules/tts.js`)

```js
const TTS_CONFIG = {
  apiKey: 'API_KEY',                 // комитнатият ключ (заключен по referrer)
  voices: {                          // закованите гласове per език
    'bg-BG': 'bg-BG-Chirp3-HD-Sadaltager',
    'en-US': 'en-US-Chirp3-HD-Sadaltager'
  },
  speakingRate: 0.85,                // 0.25..4.0 (1.0 = нормално, 0.85 = провлачено)
  breakMs: 350                       // дължина на драматичните паузи между парчетата
};
```

- `voices` — двойка `{ languageCode: voiceName }`. Кирилица → `bg-BG`, иначе `en-US`.
- `speakingRate` — 0.85 дава снизходителния, провлачен тон.
- `breakMs` — колко дълги са `<break>` паузите след пунктуация.
- ⛔ **Няма поле `pitch` и не бива да се добавя** — Chirp3-HD връща 400 при pitch и
  това би счупило ВСЯКА заявка. Дълбочината идва от самия (мъжки) глас.

> ⚠ Не пиши истинския ключ в този документ. В репото той стои само в `modules/tts.js`.

## 6. Как се държи апката без ключ

Ако ключът е плейсхолдър (`''`, `YOUR_API_KEY`, `API_KEY`), липсва мрежа или
Google върне грешка, апката **не се чупи**:

- пада към вградения `window.speechSynthesis` със същия текст;
- под бутона се показва кратка бележка (`#flavorTtsNote`), която казва **защо**:

| Бележка | Какво значи | Какво да направиш |
|---|---|---|
| *Липсва API ключ…* | `TTS_CONFIG.apiKey` е плейсхолдър | попълни ключа (т. 1) |
| *Адресът `<адрес>` не е разрешен за API ключа…* | HTTP 403 — отваряш апката от домейн, който не е в списъка | добави адреса в referrer-ите (т. 2) |
| *Няма връзка с TTS…* | мрежата пропада или Google връща друга грешка | провери мрежата |

Така апката проговаря дори без ключ и офлайн — просто с браузърния глас вместо
избрания Chirp3-HD.

## 7. Как се пишат реплики, за да звучат добре

Репликите вече не се четат само с очи. Пунктуацията е **партитура** — тя решава
къде Пийс спира да си поеме дъх. `modules/tts.js` реже репликата по пунктуация и
слага `<break>` пауза между парчетата.

### Правила

1. **Никакви съкращения с точка.** Пиши ги като цели думи:
   `т.к` → **тъй като**, `т.че` → **тъй че**, `т.н.` → **така нататък**.
   Точката вътре в съкращението прави две злини едновременно: изговорът излиза
   грешен *и* репликата се реже насред думата (`"Сигурно не плачеш,"` │ `"т."` │
   `"к дори сълзите…"`).

2. **Многоточието работи — но го пиши слято.**
   `Бърз си... колкото охлюв` ✅ — една пауза точно преди пойнтата.
   `Бърз си ... колкото охлюв` ❌ — интервалът откъсва точките в отделно парче.
   Същото важи за `?...` — слято е правилно.

3. **Не смесвай крайна пунктуация.** `тук!.` дава излишна пауза; пиши `тук!`.

4. **Пойнтата да е последна.** Последното парче се чете с `<prosody rate="80%">`
   — по-бавно и провлачено. Ако пойнтата е в средата, ефектът отива нахалост.

5. **Кои знаци колко тежат:**
   - `. ! ? …` → пауза **винаги**
   - `, ; :` → пауза само ако парчето вече е ≥ 18 знака (иначе се получават
     накъсани откъслеци)
   - `–` и `-` → **не** създават пауза; ползвай ги свободно за тире в изречението

6. **Главните букви не се чуват.** `МНОГО` звучи като `много` — за наблягане
   ползвай пунктуация или подредба на думите, не главни букви.

7. **Числа и игрови съкращения** (`d20`, `HP`, `IQ`, `AC`) се изговарят буквално и
   често зле. Ако репликата зависи от тях, изпиши ги с думи.

### Бърза проверка

След добавяне на нови реплики:

```bash
npx playwright test data-loading
```

Гейтът пази валидността на JSON-ите. За изговора няма автоматична проверка —
чуй новите реплики през бутона.
